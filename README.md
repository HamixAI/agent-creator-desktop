# Hamix desktop

Windows and macOS installers for Hamix. Source code is not in this repository.

Downloads are on the [Releases](https://github.com/HamixAI/agent-creator-desktop/releases) page. A stable release can include both installers:

| Platform | Files |
| --- | --- |
| Windows | `latest.yml` and the `.exe` installer |
| macOS | `latest-mac.yml` and the Mac installer |

The installed app checks this repository for a newer stable release.
